## 어순 (Wortstellung)

독일어 어순의 핵심은 **V2 가 "두 번째 낱말"이 아니라 "두 번째 문장성분"** 이라는 것이다.
Goethe 예문 2,472개를 세어 보니 정동사가 두 번째 *낱말*인 경우는 절반뿐이었다.

```
Vor der Abfahrt rufe ich an.        정동사가 4번째 낱말이지만 두 번째 성분
In der heutigen Gesellschaft wird leider konsumiert.
```

그래서 이 앱은 낱말이 아니라 **성분 단위**로 다루고, 채점도 정답 문자열과 비교하지 않고
**규칙을 하나씩 검사**한다 (`js/wordorder.js`). 덕분에 맞는 배열은 전부 정답이 된다.

```
Ich fahre morgen mit dem Zug nach Berlin.    정답
Morgen fahre ich mit dem Zug nach Berlin.    정답  (앞자리만 바꿨다)
Nach Berlin fahre ich morgen mit dem Zug.    정답
Ich morgen fahre mit dem Zug nach Berlin.    오답 — 정동사가 3번째 성분
Ich fahre nach Berlin morgen mit dem Zug.    오답 — TeKaMoLo 위반
```

검사하는 규칙: **V2** · **Vorfeld**(앞자리엔 성분 하나, nicht·대명사목적어 불가)
· **Satzklammer**(문장 끝 동사부) · **TeKaMoLo**(시간→이유→방법→장소)
· **목적어 순서**(명사끼리 3격→4격, 대명사가 끼면 대명사 먼저, 대명사끼리 4격→3격)
· **주어 위치** · **대명사 우선** · **nicht 위치** · 종속절 **동사 후치** · 의문문 **V2/V1**

### `문맥 속 관사 + 명사` 가 바뀐 이유

예전에는 예문에서 명사만 빈칸으로 만들었는데, 앞에 남는 관사가 문제를 망가뜨렸습니다.

- `Der ______ ist rot.` — 관사가 성을 공짜로 알려줌 (예문의 35%)
- `Soße zum ______` → 정답 `der Braten` — 3격 자리를 보여주고 1격을 요구 (15%)

지금은 **관사까지 함께 비우고 문장이 요구하는 격 그대로** 답합니다.

```
Nehmen Sie noch etwas Soße ______ ?
  B _ _ _ _ _  (6글자)
  → zum Braten
  해설: der Braten · zu + 3격 · zu dem = zum
```

관사가 없던 예문은 예전처럼 1격으로 묻습니다 (모순이 없으므로).

## 힌트와 뜻

문제 화면의 **힌트** 버튼은 누를 때만 열립니다. 뜻 → 다른 예문 순서입니다.
힌트를 쓰면 채점 결과에 `정답 (힌트 사용)` 으로 표시됩니다.

예문만으로 답이 안 정해지는 문제에는 **첫 글자 + 길이**를 항상 보여줍니다.
이건 힌트가 아니라 문제 조건입니다.

### 뜻 테스트

적어 넣은 뜻으로 바로 시험을 볼 수 있습니다. **뜻이 적힌 단어만** 출제되므로,
채우는 만큼 시험 범위가 저절로 넓어집니다. 뜻 채우기 탭 위쪽 세 버튼으로 시작합니다.

| 드릴 | 문제 | 답 |
|---|---|---|
| 뜻 맞히기 | `der Zug` | 뜻을 적음 |
| 단어 맞히기 | `기차 · 열차 · 행렬` | `der Zug` (명사는 관사까지) |

**쉼표로 여러 뜻을 적어 두면 그중 하나만 맞아도 정답입니다.**
`기차, 열차, 행렬` 이라고 적어 두었으면 `열차` 만 적어도 맞습니다.
띄어쓰기·마침표·괄호 설명 차이는 알아서 무시합니다 (`열 차`, `기차.`, `기차(교통)` 전부 정답).

그래도 답지에 없는 표현을 썼는데 사실 맞는 경우가 있습니다. 이때 채점 화면에
**`'…' 도 정답으로 인정`** 버튼이 나옵니다. 누르면

1. 그 답이 이 단어의 답지에 들어가 **다음부터 자동으로 정답** 처리되고,
2. 방금 오답으로 깎인 SRS 카드가 채점 전 상태에서 정답으로 다시 매겨지고,
3. 이번 세션 집계도 바로잡힙니다.

인정한 답은 `aliases` 로 저장되어 동기화 시 **합집합**으로 합쳐집니다 —
폰에서 인정한 답과 PC 에서 인정한 답이 둘 다 남습니다.

### 뜻 채워 넣기

**뜻은 비어 있습니다.** Goethe 원문에 번역이 없습니다. 세 군데서 적을 수 있습니다.

- **뜻 채우기 탭** — 단어가 하나씩 뜨고 아래 칸에 적고 `Enter`. 저장하고 바로 다음 단어,
  포커스도 그대로. A1 → A2 → B1 순서로 나옵니다. 몰아서 채울 때 제일 빠릅니다.
- **학습하다가 그 자리에서** — 채점 화면의 단어 정보에 입력칸이 바로 뜹니다.
- **단어장** — 행을 클릭하면 편집 패널. 뜻이 없는 행은 `＋ 뜻 적기` 로 표시됩니다.

## 항목 지우기

원문 PDF 에는 오스트리아·스위스 표기 안내(`→D, A: Friseur`)나 참고문헌 조각이
섞여 있고, 파서가 이것을 낱말로 읽어 버린 것이 **151개** 있습니다. 거의 다
형용사로 분류돼 있습니다. 뜻을 채우다 보면 25개에 한 번쯤 마주칩니다.

- **뜻 채우기** — `삭제` 버튼. 지우면 바로 다음 단어로 넘어가고 위에 되돌리기 줄이 뜹니다
- **단어장** — 행을 열면 `이 항목 삭제`. `깨진 항목만` 을 켜면 후보 151개가 모이고
  **한 번에 전부 삭제**할 수 있습니다 (되돌릴 수 있다는 확인을 거칩니다)
- **되돌리기** — `지운 것 보기 (N)` 필터에서 행을 열면 `되돌리기`

지우는 방식은 **원본을 건드리지 않고 id 만 표시**합니다.

- `tools/` 를 다시 돌려 `nouns.js` 등을 새로 만들어도 지운 상태가 유지됩니다
- **학습 카드는 남습니다** — 되돌리면 진도도 같이 돌아옵니다
- 기기 간 동기화에서 합쳐집니다 (같은 항목은 나중 시각을 씁니다)

`깨진 항목만` 판정은 **확실히 깨진 표시만** 봅니다 — 괄호·숫자·화살표·마침표·쉼표,
`-` 나 `/` 로 시작. `Geschwindigkeitsbeschränkung` 처럼 길기만 한 것이나
`Pommes frites` 처럼 두 낱말인 것은 멀쩡한 낱말이므로 잡지 않습니다.
문법·어순 항목은 손으로 쓴 문장이라 마침표가 정상이므로 아예 대상에서 뺍니다.
어디까지나 후보를 모아 주는 것이고, 지우는 것은 언제나 사람이 정합니다.

## 접두사 동사

파생 동사를 낱개로 외우면 `stehen` 하나에 딸린 일곱 개가 서로 무관한 일곱 단어가 됩니다.
**기본 동사 + 접두사 + 문법 패턴**으로 묶어 기억을 압축합니다.

다만 "접두사를 알면 뜻이 나온다"고 말하지 않습니다. `aufgeben`(포기하다)이나
`verstehen`(이해하다)은 직역으로 도달할 수 없습니다. 그래서 모든 화면에
**의미 투명도**를 붙이고, 직역은 회색 보조로만, 실제 뜻을 항상 먼저 보여줍니다.

| 투명도 | 뜻 |
|---|---|
| 예측 쉬움 | 접두사 + 기본 동사로 뜻이 대체로 보입니다 |
| 중간 | 중심 이미지는 이어지지만 실제 뜻은 따로 익혀야 합니다 |
| 개별 암기 | 직역으로 못 갑니다. 일반 단어처럼 외우세요 |

### 화면 (탭 `접두사`)

- **접두사 탐색** — 접두사 35개를 분리 / 비분리 / 둘 다 되는 것으로 나눠 카드로.
  A1 부터 순서대로 놓입니다. 카드를 열면 중심 이미지 · 대표 의미 · 문법 3형 표
  (현재 · zu부정사 · 과거분사) · 동사 목록 · `이 접두사만 연습`.
  **동사의 뜻은 눌러야 나옵니다** — 먼저 스스로 짐작해 보라는 뜻입니다.
- **기본 동사 패밀리** — `gehen` 하나에 딸린 13개를 나란히 비교합니다.
  실제 뜻 · 추론 힌트(직역) · 투명도 · 분리 여부 · 내 정답률.

### 분리 여부를 어떻게 정하는가

`verbs.js` 의 `separable` 필드를 그대로 믿으면 안 됩니다. 원문 단어장에 활용형이 없던
동사는 파서가 판정을 못 해 `null` 로 두었고, `anfangen`·`ankommen`·`mitkommen`·
`abfahren` 같은 **A1 분리동사 119개**가 여기 걸립니다. `null` 을 "비분리"로 읽으면
정반대를 가르치게 됩니다. 그래서 근거를 순서대로 봅니다.

1. `pp` 가 있으면 → 접두사 바로 뒤에 `ge` 가 오는가 (`aufgestanden` vs `verstanden`)
2. `pres3` 가 있으면 → 띄어 쓰였는가 (`steht auf` vs `versteht`)
3. 둘 다 없으면 → 접두사 종류로 추정 (`an-` 은 늘 분리, `be-` 는 늘 비분리)

3번은 **가변 접두사에는 쓰지 않습니다.** `um`·`über`·`unter`·`durch`·`wieder`·`voll`
은 동사마다 갈리므로 근거가 없으면 아예 다루지 않습니다 — 찍어서 가르치지 않습니다.

활용형이 비어 있으면 **기본 동사에서 끌어옵니다.** 파생 동사는 기본 동사와 똑같이
활용하기 때문입니다 — `abfahren` ← `fahren`(fährt · gefahren) → `fährt ab` · `abgefahren`.
원래 데이터에 값이 있으면 절대 덮어쓰지 않습니다.

### 데이터 늘리기

`data/prefixes.js`(접두사 35개) · `data/prefixverbs.js`(동사 61개)는 **손으로 쓰는 파일**이라
`tools/` 재실행에 덮이지 않습니다. 항목 하나 추가 = 객체 하나 추가이고
`lemma` 와 `meanings` 만 있으면 화면이 돕니다.

```bash
python tools/prefix_seed.py --base gehen     # gehen 계열 뼈대를 뽑아 준다
python tools/prefix_seed.py --prefix auf -n 30
python tools/prefix_seed.py --level A1
```

접두사·기본 동사·분리 여부·활용형은 자동으로 채워 주고 `meanings` 만 비워 둡니다.

앱 안 **뜻 채우기 → `접두사 동사만`** 으로 채운 뜻은 시드 없이도 바로 의미 퀴즈에
들어갑니다. 이 모드는 **기본 동사 → 그 파생어** 순으로 정렬되고, 입력칸 위에
분해 힌트(`aus + gehen` · 중심 이미지 · 기본 동사 뜻)를 띄웁니다 —
기본 동사 뜻이 있어야 추론이 성립하기 때문입니다.

### 한국어 사용자가 특히 어려운 곳

| 어려운 지점 | 대응 |
|---|---|
| 한국어에 접두사 분리가 없어 "왜 떨어져 나가나"가 안 잡힘 | 채점 뒤 문장괄호 그림 · 오히려 한국어처럼 동사가 끝에 온다는 점을 활용 |
| 과거분사 `ge` 위치 | 규칙으로 만든 3지선다를 반복 |
| 사전 뜻이 여러 개일 때 무엇이 흔한지 모름 | `freq` 순 정렬 · 첫 번째만 굵게 |
| 직역에 기대다 틀림 | 투명도 배지 상시 노출 · `개별 암기` 는 빨강 |
| `um-`·`über-` 처럼 분리 여부로 뜻이 갈림 | 접두사 카드에 경고 · `umfahren` 최소 대립쌍 고정 노출 |

## 통계

### 레벨별 정답률은 '처음 나오는 레벨' 기준

Goethe 단어장은 누적입니다. A1 단어가 A2·B1 목록에도 다시 실리므로
`levels: ['A1','A2','B1']` 은 **A1 단어**라는 뜻입니다.

레벨마다 다 세면 A1 단어를 맞힌 것이 B1 성적으로도 잡혀 등급이 뭉개집니다.
그래서 단어를 **처음 나오는 레벨 한 칸**에만 넣습니다. B2 칸에는 B2 에만 있는
2,173개 — 진짜 B2 어휘만 남습니다.

| | 처음 나오는 레벨 | 레벨마다 중복 (예전) |
|---|---|---|
| A1 | 737 | 737 |
| A2 | 615 | 1,129 |
| B1 | 1,957 | 3,015 |
| B2 | 2,173 | 2,456 |
| 합계 | **5,482** (= 전체 단어) | 7,337 |

뜻 채우기 진척도 같은 기준입니다.

### 성별 오답률은 성에 좌우되는 문제 전부

성만 고르는 문제는 둘뿐이지만 관사 격변화표·관사+명사·뜻→독일어도 성을 모르면
못 풉니다. 앞서 두 개만 세다 보니 표본이 너무 작아 `중성 —` 처럼 빈칸이 남았습니다.
지금은 `gender · genderSpell · fullForm · artDef · artIndef · artKein · artMein · meaningKo`
여덟 가지를 셉니다 (명사만).

### 뜻 관련 항목


- **장기기억 전환** — SRS 상자별 카드 수. "오늘 몇 개 풀었나"보다 이게 진짜 진도입니다.
- **이번 주 vs 지난 주** — 정답률·학습량·신규 단어의 증감
- **학습 히트맵** — 최근 12주 잔디
- **드릴별 · 레벨별 정답률** — 약한 것부터 정렬
- **자주 틀리는 단어 TOP 20** — 버튼 하나로 그것만 모아 연습
- **성별 · 복수형 유형별 오답률** — der/die/das 중 뭘 자꾸 틀리는지
- **앞으로 7일 복습 예정** — 몰리는 날이 보입니다

홈의 진도 막대는 `미학습 / 학습중 / 익숙 / 암기완료` 네 구간으로 쌓입니다.
(예전에는 7일 상자 이상만 셌더니 첫날에는 구조적으로 0이라 고장 난 것처럼 보였습니다.)

## 채점 방식

성과 철자를 **따로** 채점합니다. `die Apfel` 은 "철자는 맞고 성이 틀렸다"고 알려주고,
SRS도 성 카드만 되돌립니다.

- `ae oe ue ss` 를 쳐도 `ä ö ü ß` 로 인정 (입력창 아래 버튼도 있습니다)
- 명사를 소문자로 쓰면 정답 처리하되 경고 → 설정에서 오답 처리로 전환 가능
- 한 글자 오타는 정답 처리하고 올바른 철자를 보여줍니다

## 간격 반복 (SRS)

카드 단위가 **(표제어 × 드릴유형)** 입니다. `Apfel의 성` 을 외웠어도
`Apfel의 복수형` 은 따로 스케줄됩니다.

`다시 → 10분 → 1일 → 3일 → 7일 → 16일 → 35일 → 90일`
정답이면 한 칸 올라가고 틀리면 처음으로 돌아갑니다. 하루 신규는 기본 15개.

## 어휘를 더 넣으려면

새 PDF 를 이 폴더에 넣고 `tools/extract.py` 의 `DOCS` 에 항목 하나만 더합니다.

```python
{
    "level": "C1",
    "file": "새-단어장.pdf",
    "page_split": 300.0,        # 2단이면 나누는 x, 1단이면 None
    "boundaries": [300.0, 600.0],   # 각 단에서 표제어/예문을 가르는 x
    "first_page": 0,            # 어휘가 시작되는 쪽 (0부터)
    "y_tol": 4.0,
},
```

`boundaries` 는 실측해야 합니다. x좌표 분포를 찍으면 봉우리가 보입니다.
예문 칸이 없는 자료(교재 어휘목록)면 경계를 단의 오른쪽 끝 너머로 잡아
전부 표제어로 읽게 합니다.

```bash
python -c "
import fitz
from collections import Counter
d = fitz.open('새-단어장.pdf')
c = Counter()
for pn in range(0, 20):
    for w in d[pn].get_text('words'):
        c[round(w[0])] += 1
print(sorted(i for i in c.items() if i[1] > 30))
"
```

그다음 `tools/parse.py` 와 `tools/build.py` 의 레벨 목록에 새 레벨을 넣고,
`js/store.js` · `js/stats.js` · `js/ui.js` 의 레벨 목록에도 추가한 뒤 파이프라인을 돌립니다.

```bash
python tools/extract.py     # PDF -> tools/out/*.tsv
python tools/parse.py       # TSV -> 구조화 JSON + review.txt
python tools/build.py       # 통합 -> data/*.js
node tools/test_app.js      # 검증
python tools/build_dist.py  # 배포본 다시 만들기
```

겹치는 표제어는 레벨 태그가 누적되고 새 단어만 추가됩니다.
`tools/out/review.txt` 에 파서가 확신 못 한 항목이 모입니다 (지금 B2 는 12건).

## 왜 `file://` 제약을 신경 썼는가

브라우저는 `file://` 로 연 페이지에서 `fetch()` 와 ES 모듈을 CORS로 막습니다. 그래서

- 데이터를 `.json` 이 아니라 `window.NOUNS = [...]` 를 선언하는 `.js` 로 두고
- 전부 **클래식 `<script src>`** 로 불러옵니다

이 규칙만 지키면 서버 없이 더블클릭으로 열립니다.
